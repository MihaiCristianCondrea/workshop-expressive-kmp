WorkShop Expressive

Expressive UI Components for Kotlin Multiplatform

WorkShop Expressive is a modern, high-performance UI toolkit built entirely with Compose Multiplatform. It provides developer-first tokens, atoms, and complex molecules to accelerate the creation of educational software on Android, iOS, Desktop, and Web (Wasm).

Key Components

  • Animated Navigation Drawer with dynamic icons
  • Bouncy, tactile Buttons with interaction feedback
  • Adaptive Card surfaces with refined token-based radii
  • Type-safe Breadcrumb navigation
  • Progress indicators and semantic Input fields

Design Principles

Our system is built on four core pillars: Focus, Expression, Empowerment, and Technical Excellence. We prioritize white-first design tokens with robust Dark Mode support across all platforms.
